# Передача в реализацию

Прочитать `docs/PYJHORA_MCP_NATAL_CHART_UI_REQUIREMENTS_RU.md` и файлы этого каталога. Использовать существующий Vite + React + TypeScript, новый фон `/assets/results-space-v2.png`, GSAP и текущую чёрно-медную палитру. `components.json` отсутствует, поэтому shadcn CLI не запускать.

Fixture вынести в `src/components/results-demo-data.ts`. На экране он показывает 15 сентября 1998, 17:28, Москва, UTC+4 и Lahiri. `ResultsShowcase.tsx` использует production-компонент `SouthIndianChart.tsx`, поэтому D1, выбор знака и режимы просмотра повторяют реальный кабинет. Компонент отвечает за три вкладки, таблицы, раскрытия и локальные состояния без backend-запросов.

Три rail-иконки сохранить как прозрачные PNG в `public/assets/results-nav-*.png`; все крупные поверхности, таблицы, символы и текст строить кодом. Проверить Vitest, `npm run build`, клики и клавиатуру на 1672×941, 1569×920, 1024×768 и 390×844. На каждом размере D1 сохраняет квадрат, сводка идёт отдельным блоком, а страница не получает горизонтальный скролл.
