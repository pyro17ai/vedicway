# План E2E-проверки результата натальной карты

## Обзор

Проверка охватывает путь от формы рождения до рабочего экрана результата. Она использует локальный FastAPI-контур с тестовым платёжным провайдером: карта строится из реального расчётного снимка, а интерфейс не получает подменённые данные браузерной заглушкой.

## Сценарии

### 1. Создание карты

**Seed:** `tests/e2e/seed.spec.ts`

#### 1.1. valid-form-to-d1

**File:** `tests/e2e/valid-form-to-d1.spec.ts`

**Steps:**

1. Ввести имя, дату, время и выбрать Москву из серверных подсказок.
   - expect: форма создаёт карту и адрес содержит случайный `chart_id`.
   - expect: видна программная D1 с двенадцатью фиксированными знаками и лагной.
2. Выбрать ячейку и включить профессиональный режим.
   - expect: появляется доступное описание выбранного знака и точная координата.
   - expect: URL сохраняет `varga` и `mode`.

### 2. Доступ к подробному отчёту

**Seed:** `tests/e2e/seed.spec.ts`

#### 2.1. free-to-full-report

**File:** `tests/e2e/free-to-full-report.spec.ts`

**Steps:**

1. Создать карту и открыть вкладку объяснения.
   - expect: показаны восемь тематических карточек с фактами карты.
2. Нажать «Подробнее» и закрыть окно клавишей Escape.
   - expect: открывается диалог оплаты с ценой 990 ₽ и без подписки.
   - expect: фокус возвращается к карточке после закрытия.
3. Подтвердить тестовую оплату и запросить PDF.
   - expect: сервер открывает подробный текст только после entitlement.
   - expect: скачиваемый PDF имеет ответ `303` на защищённый файл.

### 3. Мобильная навигация

**Seed:** `tests/e2e/seed.spec.ts`

#### 3.1. mobile-tabs-and-dialog

**File:** `tests/e2e/mobile-tabs-and-dialog.spec.ts`

**Steps:**

1. Открыть результат на ширине 390 px и перейти по трём вкладкам клавиатурой.
   - expect: табы не создают горизонтальную прокрутку страницы.
   - expect: URL и активная вкладка меняются синхронно.
2. Открыть paywall.
   - expect: диалог занимает нижнюю часть экрана и удерживает фокус внутри.
   - expect: Escape закрывает диалог.
