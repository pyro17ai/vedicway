# План: технический контракт UI для PyJHora MCP

## Цель

Собрать проверенный контракт текущего PyJHora MCP и на его основе зафиксировать требования к странице натальной карты веб-сервиса. Страница состоит из трёх вкладок: южноиндийская карта и расчётные данные, объяснение результатов, вопросы пользователя.

## Источники и границы

- читать только активный checkout PyJHora MCP, его локальные инструкции, тесты и точный GitHub-репозиторий;
- проверить конфигурацию MCP, реальный runtime и все 22 зарегистрированных инструмента;
- использовать дату 16.10.2006, 13:30, Москва как контрольный вход;
- не включать в спецификацию геометрию северного, восточного или западного стиля;
- не менять исходный checkout MCP, поскольку в нём уже есть пользовательские незакоммиченные изменения.

## Рабочие шаги

1. Зафиксировать активный root, command, runtime, конфигурацию, GitHub remote и расхождения документации с кодом.
2. Составить инвентарь входных моделей, групп tools, форматов ответа, ошибок и ограничений.
3. Выполнить живой вызов всех 22 tools и отдельные проверки D1, Panchanga, варг, dashas, yogas и strength.
4. Сравнить инструменты, которые возвращают положения планет, и выбрать канонический источник для отрисовки D1.
5. Спроектировать фиксированную South Indian grid, слой домов, таблицы и три вкладки поверх фактических полей MCP.
6. Выпустить технический документ с требованиями, адаптером данных, состояниями, P0-дефектами и приёмочными тестами.
7. Проверить документ, ссылки, отсутствие незаполненных мест и результаты тестов перед передачей.

## Критерии готовности

- в документе перечислены все 22 tools и назначение каждого;
- D1 привязан к одному явно названному источнику;
- South Indian grid задан фиксированным соответствием знаков и ячеек;
- отдельно описаны D1, Bhava chart, D2–D60, Panchanga, dashas, yogas, doshas, Raja Yogas и strength;
- зафиксированы реальные ошибки и расхождения текущего runtime;
- требования к вкладке вопросов не приписывают MCP несуществующий tool;
- проверены активные тесты MCP и синтаксис исходников.
