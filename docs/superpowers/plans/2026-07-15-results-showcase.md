# Интерактивный блок результата: план реализации

> **Для агентных исполнителей:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Цель:** добавить под первым экраном единый демонстрационный блок результата с тремя состояниями из референсов: натальная карта, объяснение и вопросы к себе.

**Архитектура:** React-компонент `ResultsShowcase` хранит выбранную вкладку и управляет доступной навигацией. Содержимое состояний остаётся локальным и статическим, круг карты строится отдельным SVG-компонентом. GSAP анимирует только появление сменившейся панели и соблюдает `prefers-reduced-motion`. Фотография из четвёртого референса служит фоном секции.

**Стек:** React 19.2.7, TypeScript 7.0.2, Vite 8.1.4, GSAP 3.15.0, Lucide React 1.24.0, Vitest 4.1.10, Testing Library, Playwright CLI.

## Глобальные ограничения

- Внутри нового блока нет логотипа и надписи VedicWay.
- Публичный текст не упоминает Hermes, искусственный интеллект и ведическую астрологию.
- Основные вкладки работают мышью и клавишами ArrowUp, ArrowDown, Home, End.
- Натальная карта и символы строятся кодом; GPT Image 2 не используется без визуальной необходимости.
- Существующая папка `VedicWay Light Version/` остаётся нетронутой.
- Работа выполняется в текущей ветке по прямому запросу пользователя; отдельные коммиты не создаются без просьбы.
