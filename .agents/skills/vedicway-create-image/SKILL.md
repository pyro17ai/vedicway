# Create Image для VedicWay

Примени системный `$imagegen` в режиме встроенного `image_gen` tool. Для каждого самостоятельного изображения сделай отдельный встроенный вызов. Не используй OpenAI API, CLI fallback, `OPENAI_API_KEY`, imagegen-MCP, Pillow, SVG, Canvas или HTML для генерации.

Передай содержательный русский prompt: назначение, точный текст при наличии, композицию, палитру и запрет на чужие логотипы или водяные знаки. Проверь готовое изображение внутри ответа инструмента. Если обязательный текст искажён, создай исправленную версию ещё одним встроенным вызовом и используй только проверенный вариант.

Встроенный инструмент сохраняет файл в `CODEX_HOME/generated_images`. Вызови `vedicway_import_generated_image` из MCP `vedicway-control` вместе с `kind` и уникальным относительным `.webp`-путём. Передай абсолютный `source_path`, если `image_gen` вернул его; если путь отсутствует, не выдумывай его и вызови импорт без `source_path`, тогда control выберет свежий, ещё не импортированный файл текущего run. Этот инструмент только проверяет, приводит к размеру контракта и переносит уже созданный файл в хранилище VedicWay. Прими результат при `generator=codex-imagegen`, ожидаемых размерах и непустом SHA-256, затем используй путь и SHA-256 в записи media. Если системный `$imagegen` недоступен, заверши run как blocked без API-fallback.
