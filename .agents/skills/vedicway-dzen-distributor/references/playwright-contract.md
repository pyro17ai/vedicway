# Контракт браузерной публикации в Дзен

Рабочий профиль VedicWay хранится отдельно от репозитория и профилей других проектов. Playwright подключается к уже запущенному Chromium по CDP; автономный run не запускает второй браузер с тем же каталогом.

Публикация проходит через видимый редактор Дзен-студии. Приватные endpoint допустимы только как диагностическое наблюдение браузера и не заменяют клики, ввод, загрузку медиа и финальную кнопку публикации.

Успех требует повторного чтения сохраненного редактора и открытия публичного URL. Вход, CAPTCHA, отсутствие канала или изменение обязательного диалога дают blocker либо failed без попытки обхода.
