# Официальный RSS-контракт Дзена

- Подключение сайта к каналу: https://dzen.ru/help/ru/website/site-to-channel.html
- Требования к сайту: https://dzen.ru/help/ru/website/website-requirements.html
- Формат RSS: https://dzen.ru/help/ru/website/rss-modify.html
- Правила контента: https://dzen.ru/help/ru/requirements/rules.html

VedicWay публикует feed по адресу `/feed/dzen.xml`. Stable GUID равен canonical URL. Режим `VEDICWAY_DZEN_PUBLICATION_MODE=native-draft` сохраняется до ручной приемки канала; `publish` включается только решением владельца.
