# Quality gate статьи VedicWay

Запусти `python -m seo_agent.quality_gate MANIFEST`. Нулевой код означает прохождение детерминированных правил; код 1 требует исправлений; код 2 означает техническую ошибку. Manifest версии `2.0` обязан находиться внутри `VEDICWAY_SEO_DATA_DIR`, а текст статьи передаётся как семантический HTML в `article.content_html`.

После автоматической проверки вручную сопоставь каждый раздел с brief и evidence. Проверь факты по открытым источникам, отсутствие выдуманных цитат, самостоятельность формулировок и фактическую пользу по сравнению с текущей выдачей. AI-текст без авторской проверки, повторение запроса и серийная генерация тонких страниц запрещены правилами Яндекса.

Статья проваливает gate при обещании результата, медицинском совете, маскировке астрологической интерпретации под научный факт, неясном происхождении изображения или ссылке на несуществующую страницу. Не добавляй H1, CTA, хлебные крошки и системные поля Schema.org внутрь HTML: их строит сайт. Пройденный gate требует cover шириной не меньше 1200 px, осмысленного alt и подтвержденного права использования.

Добавь к автоматическому отчету объект `manual_checks` с четырьмя полями из ledger-контракта и запиши его как `draft-quality` через `$vedicway-seo-ledger`. Поле `passed` принимает только JSON boolean. Не переводи draft в `approved`, если хоть одна ручная проверка осталась незавершенной.
