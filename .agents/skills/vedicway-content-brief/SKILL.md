# Контент-бриф VedicWay

Забери один `cluster` через `$vedicway-seo-ledger`. Бриф без действующего `claim_token` запрещен.

## Состав брифа

Зафиксируй основной запрос, проблему читателя и критерий полного ответа. Построй план из 4-8 H2, где каждый раздел решает отдельную подзадачу. Для каждого фактического утверждения укажи источник или отметь его как редакционное объяснение. Добавь минимум две существующие внутренние страницы, одну естественную точку перехода к расчету натальной карты и список утверждений, которых нельзя делать.

Астрологические трактовки подавай как систему интерпретации, а не научно доказанную причинность. Не обещай события, лечение, финансовый результат или точность рождения. Если тема требует положения планет на дату, рассчитай его через repo-local `$vedic-astrology` и сохрани параметры расчета в evidence.

## Выпуск

Бриф получает статус `approved`, только если SERP и спрос свежие, интент однозначен, статья не каннибализирует опубликованный URL и VedicWay способен подтвердить все ключевые факты. Вычисли SHA-256 канонического JSON и запиши `brief` через ledger CLI. Эта запись освобождает аренду кластера.

Используй поля из [схемы брифа](references/brief-contract.md).
