# Медиа статьи VedicWay

Для гарантированной production-обложки вызови `python -m seo_agent.media --title TITLE --category CATEGORY --output PATH.webp`. Путь обязан находиться внутри `VEDICWAY_SEO_DATA_DIR`; генератор создает WebP 1200x630 и возвращает SHA-256.

Можно использовать собственный снимок, лицензированный материал или изображение, созданное разрешенным генератором. В каждом случае сохрани `source_kind`, исходный URL при наличии и точную `license_note`. Изображение из поисковой выдачи без лицензии запрещено.

Одна статья получает ровно одну cover. Body-изображение добавляй только когда оно объясняет схему, пример карты или последовательность действий. Для каждого body asset вставь отдельный placeholder вида `{{media:body-1}}` в Markdown. Alt описывает содержание картинки без повторения SEO-запроса.

Посчитай SHA-256 исходного файла и запиши `media` через `$vedicway-seo-ledger`. Файлы за пределами каталога агента не читай и не передавай внутреннему API.
