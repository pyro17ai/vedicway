# Медиа статьи VedicWay

Production-обложку готовь только через `$vedicway-article-cover-image`. Pinterest-карточки готовь только через `$vedicway-pinterest-card-image`. Этот Skill отвечает за происхождение, alt и связь media с manifest, но сам изображения не генерирует.

Можно использовать собственный снимок, лицензированный материал или изображение, созданное разрешенным генератором. В каждом случае сохрани `source_kind`, исходный URL при наличии и точную `license_note`. Изображение из поисковой выдачи без лицензии запрещено.

Одна статья получает ровно одну cover. Body-изображение добавляй только когда оно объясняет схему, пример карты или последовательность действий. Для каждого body asset вставь отдельный placeholder вида `{{media:body-1}}` между верхнеуровневыми блоками сырого HTML. Не оборачивай placeholder в `<p>` или `<figure>`: публикатор сам заменит его серверным media marker. Alt описывает содержание картинки без повторения SEO-запроса.

Для Pinterest подготовь ровно 10 самостоятельных обучающих карточек. Все карточки различаются текстом и SHA-256, дают законченные памятки по астрологии и не требуют чтения статьи. Запиши каждую как отдельный body media с `distribution_role: pinterest`; в HTML статьи такие assets не вставляй. Site publisher загрузит их как public-unlisted media: прямой UUID-адрес доступен Pinterest, но карточка не появляется в статье, каталоге или sitemap.

При `claim draft` сначала проверь массив `media`. Если в нём уже есть одна обложка 1200x630 и ровно десять записей 1000x1500 с `distribution_role=pinterest`, используй их без новых вызовов Image Gen. Недостающие assets дозаполни только до этого количества; дубликаты и повторная генерация полной пачки запрещены.

Используй SHA-256 из ответа `vedicway_import_generated_image` и запиши `media` через `$vedicway-seo-ledger`. Файлы за пределами каталога агента не читай и не передавай внутреннему API.
