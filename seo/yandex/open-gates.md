# Внешние условия публикации

Технический контур готовится под `https://vedicway.ru`, однако репозиторий не содержит права на домен, ID счётчика Метрики, файла подтверждения Вебмастера и реквизитов оператора персональных данных. Эти значения нельзя выдумывать или брать из чужих проектов.

Перед production-релизом владелец должен добавить домен в Яндекс Вебмастер, положить выданный им HTML-файл в `public`, создать отдельный счётчик Метрики для `vedicway.ru` и записать ID в секрет окружения `VITE_YANDEX_METRIKA_COUNTER_ID`. Счётчик загружается только после согласия на аналитические cookie. Юридические страницы и подвал получают фактическое наименование оператора, ИНН, ОГРН и адрес из production-секретов либо согласованного конфигурационного файла.
